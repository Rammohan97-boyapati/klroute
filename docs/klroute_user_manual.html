klroute User Manual

Waveguide and metal routing for KLayout. Click two points, or a chain of components, and klroute draws an editable route that follows your PDK's rules, with grating couplers, test labels, vias and SiEPIC pins where they are needed.

Version 0.38.1 · KLayout 0.28 or newer · for SiEPIC and SiEPIC-compatible PDKs

1What klroute does

klroute adds two routing tools to KLayout: one for waveguides and one for metal. Each has its own window of settings and its own toolbar button.

  • Waveguides get circular or Euler bends at your bend radius. A PDK waveguide type (for example Strip TE 1550 nm, w=500 nm from the technology's WAVEGUIDES.xml) is drawn with all of its layers, as the PDK's own Waveguide cell, or built from the PDK's bend and straight cells.
  • Metal gets square corners and is drawn as the PDK's own wire cell (for example Wireguide), with a via where it lands on another metal.
  • Every route stays editable. Drag a corner with KLayout's Partial tool and the route is redrawn. Double-click it to change its type, width or layers.
  • The shape is chosen for you. In Auto-route mode klroute tries straight, L, Z, S-bend, U-turn and detour shapes and keeps the shortest one that fits the bend radius. It can also find a path around other devices.
  • Test structures: grating couplers at the route ends, SiEPIC opt_in / out_ labels, electrical elec_ labels, and a test-coordinate list you can save.
  • Your own devices: klroute can add SiEPIC pins and a DevRec outline to cells you draw yourself, so they can be routed to and verified.

Demo video

A three-minute narrated walkthrough on the SiEPIC EBeam PDK: Chain mode builds an MZI, KLayout's Partial tool reshapes its arm (dragging a segment, and adding a point and dragging a side), auto-route goes around a device, a metal route changes layer, Bridge crosses a wire, and Add Pins and Attach finish it off.

2Installing

klroute is a KLayout Salt package. It is a folder named klroute that sits in KLayout's salt folder.

Requirements

  • KLayout 0.28 or newer. Tested with 0.30.12 on Windows.
  • A SiEPIC or SiEPIC-compatible PDK (for example SiEPIC EBeam) installed as a KLayout technology, with its library loading. klroute reads its waveguide types, grating couplers, bend and wire cells. Without a PDK, klroute still routes, but on layers you choose and as its own Route cells.
  • SiEPIC-Tools (Tools → Manage Packages → siepic_tools). SiEPIC PDKs and SiEPIC verification need it.

Install from the zip (any PC)

  1. Copy klroute-0.38.1.zip to the PC.
  2. Unzip it into KLayout's salt folder: C:\Users\<name>\KLayout\salt\ on Windows, ~/.klayout/salt/ on Linux and macOS. Create the salt folder if it does not exist.
  3. Check the result is exactly …\KLayout\salt\klroute\grain.xml. Windows' Extract All may add an extra folder (salt\klroute-0.38.1\klroute); if so, move the inner klroute folder up into salt.
  4. Restart KLayout.

On Windows, one PowerShell command does steps 2 and 3:

Expand-Archive -Path "$HOME\Downloads\klroute-0.38.1.zip" -DestinationPath "$env:USERPROFILE\KLayout\salt" -Force

Install from the project folder

If the PC has Python and a copy of the project folder, run this inside the folder. It installs into that PC's KLayout\salt\klroute:

python install.py

python install.py --zip builds the zip to share, and python install.py --uninstall removes klroute.

Check it worked

  • Tools → Manage Packages lists klroute.
  • There is a menu Tools → Route (Waveguide / Metal).
  • The toolbar has Waveguide Route and Metal Route buttons. They may be hidden under the toolbar's » overflow arrow.

Update or remove

To update, close KLayout, delete salt\klroute, unzip the new version the same way and restart. Layouts you made before keep working, because every route cell is rebuilt from its saved settings. To remove klroute, delete salt\klroute or remove it in Tools → Manage Packages.

Setting klroute up for your PDK

The built-in settings follow the SiEPIC conventions:

SettingBuilt-in
Waveguide core (pin finder)Si 1/0, SiN 4/0
MetalsM2_router 12/0 (default), M1_heater 11/0, and M1, M2, M3, Metal1–Metal3 if they exist
Metal pairsM2_router ↔ M1_heater as a contact pad, with no cut layer
Pins, outlines, labelsPinRec 1/10, PinRecM 1/11, DevRec 68/0, FbrTgt 81/0, Text 10/0
opt_in label positionthe GC tip (SiEPIC rule)

For a PDK with other layer names, metal stack or via rules, put a file klroute_profile.json in the PDK's technology folder (the folder with its .lyt file). klroute uses it for every layout of that technology, and on every computer where the PDK is installed with this file. When you switch between layouts of different technologies, klroute switches settings with them.

A klroute_profile.json in your KLayout user folder (%USERPROFILE%\KLayout on Windows, ~/.klayout on Linux and macOS) applies to every technology; the technology folder's file wins over it. Their keys replace the built-in ones:

{
  "core": [["Si", "1/0"]],
  "contact_metals": [["M1", "41/0"], ["M2", "45/0"]],
  "metals": ["M1", "M2", "M3"],
  "default_metal": "M1",
  "via_pairs": {"M1": ["M2", "VIA1"], "M2": ["M1", "VIA1"]},
  "via_cuts": [["M1", "M2", "VIA1"], ["M2", "M3", "VIA2"]],
  "default_cut": "VIA1",
  "via_unit": 5.0, "via_cut": 0.8, "via_pitch": 1.4, "via_enclosure": 0.7,
  "label_at": "fiber"
}
  • core, contact_metals: layer name and fallback layer/datatype, used by the pin finder.
  • metals, default_metal: the metals offered for routes, layer changes and bridges.
  • via_pairs: each metal's usual partner and the cut layer between them (automatic vias). via_cuts: the cut layer of any metal pair. An empty cut means a contact pad without a cut layer.
  • via_unit, via_cut, via_pitch, via_enclosure: the default via geometry in the Via dialog.
  • label_at: "gc_origin" puts opt_in labels at the GC tip, "fiber" on the fiber target.

These files belong to the PDK, not to klroute, and are never part of the klroute package. When you copy the PDK to another computer, copy its klroute_profile.json with it. Restart KLayout after changing the file.

3Your first route

This example connects a grating coupler to a ring resonator with a Strip TE 1550 nm, w=500 nm waveguide (SiEPIC EBeam names; use the equivalents of your PDK).

  1. Open or create a layout with your PDK's technology. Place a grating coupler (for example ebeam_gc_te1550) and a device such as a ring resonator from the PDK library.
  2. Press Ctrl+Shift+R. The Waveguide Route window opens on the right and the tool is active.
  3. In the window, set PDK waveguide to Strip TE 1550 nm, w=500 nm and Click mode to Auto-route: click A, then B.
  4. Move the mouse to the GC's pin. A small box shows that the click will snap onto the port. Click.
  5. Move to the device's opt1 pin and click. The route is drawn, leaving and arriving along the pin directions.
  6. To change it later, select the route and drag a corner with the Partial tool, or double-click it to edit its settings.

The panel at the bottom of the window reports what was placed, the route length and the number of bends. Every route is one undo step (Ctrl+Z).

5Click modes

The Click mode list at the top of each window decides what a click in the layout does while the tool is active.

Path both

Click each corner like KLayout's Path tool. Double-click or Enter to finish.

Auto-route both

Click A, then B. klroute chooses the shape and can route around devices.

Chain both

Click components one after another; each pair is linked with one route.

Pin both

Click a waveguide end or metal contact to add a SiEPIC pin to the current cell.

Attach both

Click a component, then another; the first is moved so its pin sits on the second's pin.

Label waveguide

Click any grating coupler to add an opt_in / out_ test label.

Bridge metal

Click two points on a metal route; the part between moves to another metal, with vias.

Label metal

Click a pad, wire or contact to add an elec_<ID>_<pad> label.

In every mode, right-click or Esc cancels what you started.

Path mode

  • Click each corner. Double-click or press Enter to finish. Backspace removes the last point.
  • Segments limits each segment to Manhattan (90°), 45° or Any angle.
  • Clicks snap to the grid and to device ports. Clicking a port after the first point finishes the route there.
  • A live preview follows the mouse.

Auto-route mode

  • Click start point A, then end point B.
  • Leave A towards / Leave B towards set the direction the route leaves each point (auto, E, W, N, S). On a device port, the port's own direction is used.
  • With Route around other devices on, the route avoids other components (see section 13).

Typing coordinates instead of clicking

In Path mode, type the corners in Points [um] as 0,0; 100,0; 100,50. In Auto mode, fill in A x / y and B x / y. Then press Create route from these points. You can also draw rulers and use Tools → Route → Route Along Selected Rulers.

6Routing waveguides waveguide

Choosing the waveguide

  • PDK waveguide lists the types in the technology's WAVEGUIDES.xml, for example (SiEPIC EBeam) Strip TE 1550 nm, w=500 nm, Strip TE 1310 nm, w=350 nm or Rib (90 nm slab) TE 1550 nm, w=500 nm. Every layer of the type is drawn, including side strips and the DevRec band, and the width and bend radius come from the type.
  • Custom (settings below) uses your own Layer, Width and Bend radius, with an optional Cladding layer widened by Cladding / side. The Layer box starts empty each time KLayout opens; choose a layer before routing a Custom waveguide.
  • Bend: circular or euler. For Euler bends the radius is the minimum radius, at the middle of the bend.
  • Cladding layer and Cladding / side start empty (none) each time KLayout opens; a cladding is only drawn when both are set.

Building the route from PDK bend cells

Bend cell chooses how the corners are made:

  • none (default): the bends are drawn, circular or Euler, at the bend radius.
  • auto: the PDK bend cell of the waveguide type, named <waveguide type>_Bend.
  • Any 90° bend cell of the library, listed with its radius taken from its pins, for example <type>_Bend (radius 10 um).

With a bend cell, every corner is that PDK bend cell and every straight stretch is the matching PDK straight cell (<waveguide type>_Straight, its length set to fit). If there is no straight cell, the straights are drawn instead. The radius comes from the bend cell, so the Bend radius box shows it and is locked. The route is still one editable cell: drag a corner and the cells are placed again. All pins meet, so SiEPIC sees one connected chain. Bend cells need horizontal and vertical segments only.

What gets placed

Create as decides the kind of object:

Create asResult
Editable cell (default)A PDK waveguide type with horizontal or vertical end segments becomes the PDK's own Waveguide cell (from the technology's library), with its pins, DevRec and model labels. Anything else becomes a klroute → Route cell. Both are editable.
Path (fixed)Plain path shapes. They are not redrawn when edited.
Polygon (fixed)Plain polygons.

A PDK Waveguide cell needs horizontal or vertical end segments, because its pins go there. A route whose first or last segment is diagonal is placed as a klroute Route cell instead, and the panel says so.

Editing a route

  • Select it and drag a corner with the Partial tool. The bends are redrawn; grating couplers and labels inside the route cell follow.
  • Double-click it, or open Properties, to change the waveguide type, width, radius or layers.

Snapping to device ports

With Snap route ends to device ports on (the default), a click within about 12 screen pixels of an optical port (a SiEPIC pin such as opt1) snaps exactly onto it. The route leaves and arrives along the port's direction, with a straight lead of at least twice the bend radius where needed.

7Grating couplers and test labels waveguide

Grating couplers at the route ends

  • Set Grating couplers to Input (A) and output (B), Input (A) only or Output (B) only.
  • GC cell: auto picks the GC that matches the waveguide type's wavelength and polarization (for example ebeam_gc_te1550 for a TE 1550 nm type), or choose one.
  • The GC's opt1 pin sits exactly on the route end, facing away from the route. GCs are only placed at free ends, never on a device port.
  • With Editable cell, the route, its GCs and its labels form one klroute Route cell, so they move together when you edit the route.

Test labels

With Test label at the GC fiber target on, labels go on the Text layer (10/0) at each GC's fiber target:

input GC :  opt_in_<TE|TM>_<1550|1310>_device_<deviceID>
output GC:  out_<TE|TM>_<1550|1310>_device_<deviceID>
  • Polarization sets TE or TM. The wavelength comes from the GC name (1550, 1310, …).
  • Device ID: leave it empty to use route1, route2, … or, when the route ends on a device, an ID from the device such as ring-X0-Y0. A _ in the ID is replaced by -, because SiEPIC splits labels on _.
  • Label: auto gives the first GC of a device opt_in_… and the second out_…; or force input or output.
  • The output label has no "opt" in it, so SiEPIC's own tools still see exactly one input per device.

Labelling a GC you placed yourself (Label mode)

For a coupler klroute did not place (your own cell, or one from another library), set Click mode to Label: click any grating coupler… and click it. It works on any cell. A dialog asks:

FieldDefault
Label typeInput (opt_in_…), Output (out_…) (suggested for the device you labelled last) or Custom text
Polarization, wavelengthread from the cell name: MyCoupler_TM1310 gives TM, 1310
Type, Device IDdevice; the window's Device ID or the next free routeN
Positionthe fiber target (if the cell has one), the GC tip / cell origin (SiEPIC rule), or where you clicked

8Connecting a device to a GC array waveguide

  1. Select a placed device with the Select tool.
  2. Set GC array side (left, right, top, bottom), GC array pitch (default 127 µm, the fiber-array pitch) and Input port (opt_in) (default opt1).
  3. Press Connect selected device → GC array, or use Tools → Route → Connect Selected Device to GC Array.
  • Every free optical port gets its own GC in one column, routed without crossings. Ports facing away from the GCs escape around the device on nested levels.
  • Route spacing: auto keeps parallel routes apart by the widest band (DevRec) + 1 µm, so SiEPIC DevRecs don't overlap.
  • The input port's GC gets opt_in_…, all others out_…, with one device ID.

9Routing metal metal

  • Layer: the technology's layers are listed, for example M2_router (12/0). Layer selected in layer panel uses whatever layer is current in KLayout's layer list. The box starts empty each time KLayout opens: choose a layer, or a specific PDK wire cell (which sets its layer), before routing.
  • Width [um]: the trace width. Corners are always square.
  • PDK wire cell chooses the cell that is placed:
    • auto (default): the PDK wire cell of the chosen layer, for example Wireguide for M2_router in SiEPIC EBeam.
    • none: a klroute Route cell with the same layers as the PDK wire.
    • A specific wire cell from the library. Choosing one also sets Layer to its metal.
  • Metal without a PDK wire cell is placed as a klroute Route cell.
  • Electrical pins (pin1 / pin2 on PinRecM) are drawn at both ends, so metal routes can be chained and attached.

Saving and reopening. Some PDKs register cells with a leading space in the name (" Wire_X"), which KLayout loses when it reads a file back. klroute registers the same cells once more under the clean names, so such cells reopen as editable PDK cells on any PC where klroute is installed.

10Vias and layer changes metal

Automatic vias at route ends

With Add a via where an end lands on the other metal on, a route that ends on the other metal (for example an M1 route ending on a pad that is only on M2) gets a via there. If the end is on a pad edge, the via is moved fully inside the pad, and the route runs on across the whole via. Via block: auto uses the route width rounded up to 5 µm.

Changing layer while drawing

In Path mode, at the corner where the route should continue on another metal:

  • Shift+click the corner, or
  • press V right after clicking it, or
  • press Change metal layer here (via) in the window.

The Via dialog opens (below). The preview shows a via box at that corner and the status bar shows the layer order, for example M1 → M2 → M1. Do it again at a later corner to switch back, or at the same corner to undo it. When you finish, each stretch is placed on its own metal with a via centred on every change point, all as one undo step. Both metals run across the whole via, so each one covers it completely.

Bridge mode: hop over a crossing wire

  1. In the Metal Route window set Click mode to Bridge.
  2. Click a point on a metal route before the wire you want to cross, then a point after it. Clicks snap onto the route's centre line.
  3. Choose the bridge metal and via in the Via dialog.

The part between your clicks moves to the chosen metal, and a via goes on each break. The bridged part may include corners. One Ctrl+Z undoes it.

  • The dialog shows the result as you type, for example Block 10 x 10 um: 2 x 2 tile(s) of 5 um, 3 x 3 cuts each (36 cuts of 0.8 um).

12Chain mode both

Chain mode links components two at a time. Set Click mode to Chain, start the tool, and click components in order, for example GC → device → GC. Each click links the clicked component to the previous one with one route, and the chain continues from the component you just clicked. Routes and via cells are never picked as chain components, and a click just next to a small component (within a few screen pixels) picks it, so you can zoom far out for long links.

For every link a dialog asks:

RowWhat you choose
PDK waveguide / PDK wire cellthe waveguide type or wire cell for this link. The window's setting is preselected; a different choice becomes the window's setting for the next links too
Bend cellwaveguide only: none (drawn bends), auto, or a PDK bend cell for this link. Preselected from the window; a different choice becomes the window's setting too
1st: <component> portwhich free port of the first component (the best one is preselected)
2nd: <component> portwhich free port of the second component
Label at <GC>waveguide only: No label, Input (opt_in) or Output (out_) for each GC in the link. Input is suggested for a GC clicked before the device
Device IDprefilled from the device, e.g. ring-X0-Y0
  • Cancel skips that link. Untick Chain: ask ports and label for every link to let klroute choose ports and labels itself.
  • Double-click, Enter, Esc or right-click ends the chain. Links already made stay.
  • Metal chains use electrical pins (PinRecM). A component with no electrical pins, such as a bond pad, is connected at the middle of the side that gives the shortest wire.

13Routing around other devices both

With Route around other devices on, auto-routes and chain links stay clear of other components.

Grid. The detour is searched on the grid of the layout view (KLayout's editing grid, else its display grid): the search pitch is the largest multiple of that grid not above about half the bend radius (and not above 1.9× the clearance), and the grid lines lie on the view grid, so every corner of a detour is on your grid. The leads out of the ports run on to the next grid line; only coordinates in line with an off-grid port keep the port's own value. A view grid coarser than that is used as it is, and each grid step is then also checked against the devices. Routes of several millimetres take a second or two.

  • Waveguides avoid every component's DevRec (or its bounding box if it has none), grown by half the route's widest band + 0.5 µm, so DevRecs never overlap.
  • Metal always avoids other metal on its own layers, by half the width plus a spacing (Detour clearance, or 1× the width on auto). The pad or wire at your start and end is the same net and is not an obstacle. It may cross routes of other metal layers. With Also avoid optical devices on, it avoids device DevRecs too (the DevRec of metal routes and vias does not count, so crossing another metal stays possible); switch that off when a wire must run over a device, for example to a heater.
  • If the straight route is already clear it is kept. Otherwise a grid search finds a Manhattan path where every turn fits the bend radius, preferring fewer bends.
  • A route starting on a pin deep inside its own device first goes straight out along the pin until it is clear of the device.
  • Path mode keeps your corners exactly and is never rerouted.

14Attach both

Attach joins two components pin to pin without a route, for example a GC directly on a device port.

  1. Set Click mode to Attach and start the tool.
  2. Click the component to move, then the component to attach it to.
  3. In the dialog pick the two pins. The closest free pair is suggested; pins already in use are marked connected.
  • The first component is moved, and turned by 90°, 180° or 270° if needed, so its pin sits exactly on the second pin, facing it.
  • The Waveguide window uses optical pins, the Metal window electrical pins. A plain pad offers the middles of its metal edges.
  • What follows it: components attached to the moved one, their labels, and routes connected to it. A route with one end on the moved component is re-routed: its far end stays, its near end goes to the new pin position.
  • You can also select two components (click, then Shift+click) and press Attach selected: 1st selected → 2nd selected….
  • One Ctrl+Z undoes the whole attach.

Moving a device with KLayout's own Move tool does not re-route its routes. Use Attach, or redraw the route.

15Pins and DevRec for your own devices both

klroute routes to SiEPIC pins. Cells from the PDK already have them; cells you draw yourself need them added.

Adding pins automatically

Select your device instance (or make the device the current cell) and press Add pins to selected device (or current cell)…. The dialog shows two layer lists, Waveguide layers and Metal layers: the layers searched for ports. They are ticked from the PDK profile when its layers are in the cell; otherwise klroute guesses from the cell itself (metal: layers named like a metal, wire, heater or pad; waveguide: the other layers with narrow open ends on the cell's outline). Change the ticks and press Find pins to search again; your ticks are remembered for the technology and used by Pin mode too. The list below shows what was found; untick pins you don't want or double-click to rename, then press Add. This works with any SiEPIC-compatible PDK, also when its layers are not in the profile.

  • Optical pins opt1, opt2, … on PinRec (1/10) at the open waveguide ends (core layers of the profile, e.g. Si) on the device's outer edge, numbered anticlockwise from the west side.
  • Electrical pins elec1, elec2, … on PinRecM (1/11), one per separate metal contact; a pad stacked on two metals gets one pin.

Adding pins by clicking (Pin mode)

For ends inside a device, or anywhere the automatic finder misses, set Click mode to Pin and click the waveguide end or contact. Choose the name, type (optical or electrical), direction and width. Pin mode looks on the same layers as Add pins: the ones you last ticked in that dialog for this technology, else the profile's, else a guess from the shapes around your click. The pin always goes into the current cell, the cell shown in the view: open your device with Descend or Show As New Top to put the pin inside it.

Adding a DevRec box

Press Add DevRec box to selected device (or current cell)…. The box covers the device's shapes on every layer except PinRec, PinRecM, DevRec and Text. Set a margin in the dialog, and tick Replace to remove an existing DevRec.

Putting your cells in a library

Select an instance of your device (or a cell in the Cells tree; with nothing selected, the current cell is used) and press Add selected cell to a library…, or use Tools → Route → Add Selected Cell to Library….

  • Library: choose one of your libraries or type a name for a new one (letters, digits, _ and -).
  • Name in the library: the cell's name there; tick Replace to overwrite a cell of the same name.
  • Only for technology …: the library shows only for layouts of that technology.

The cell is copied with all its sub-cells. Your own sub-cells are copied too; PDK cells and PCells inside it (grating couplers, waveguides, routes) stay references to their library, so they remain editable and are recognised by SiEPIC. The library is saved as <KLayout folder>\klroute_libraries\<name>.gds and is loaded every time KLayout starts. Place its cells from the Libraries panel like any PDK cell. Tools → Route → Remove Cells / Delete Library… deletes selected cells from a library, or the whole library with Delete whole library… (after a confirmation; this cannot be undone). To use a library on another PC, copy its .gds and .json into the same folder there.

16Labels that move with their pads and GCs both

Labels made in Label mode, and the GC labels Chain mode adds, are tied to the component they label. KLayout's own Move, Rotate, Mirror and Copy keep them on it, and Ctrl+Z undoes both together.

  • Your own cell placed once: the label goes inside that cell.
  • A PDK pad or GC, or a cell placed several times: the instance and its label are grouped into a new cell LBL_<cell>, placed exactly where the instance was. To move it, select the LBL_ instance. Routes stay connected.
  • Metal drawn directly in the layout (not a cell): the label stays loose text.

A copy of a labelled pad carries the same label; relabel the copy with Replace ticked. Labels made before version 0.27 are loose text and do not follow; relabel them the same way.

18SiEPIC verification

With SiEPIC pins (opt1/opt2) on waveguide ends and Add DevRec around waveguide routes on (both are the default), every waveguide route is a SiEPIC component, so SiEPIC's Functional Verification sees it connected to the GCs and devices at its ends. The two are separate: a route can get its DevRec outline without pins. A PDK Waveguide cell brings its own pins and DevRec.

  • A PDK waveguide type with Manhattan ends is the PDK's Waveguide cell, which has its own pins.
  • Anything else is a Route_wg cell with opt1 / opt2 pins, a DevRec outline and the compact-model texts SiEPIC reads (Component=, Spice_param:, …).
  • Metal routes carry pin1 / pin2 on PinRecM, like PDK wire cells.

Messages you can expect:

  • Disconnected pin: an open route end, or an unused port of a device.
  • Overlapping component at a device whose ports are closer together than the waveguide's DevRec band (for example a compact 1×2 splitter). The cores do not touch.
  • A GC placed on a diagonal route end is rotated at a non-90° angle, which SiEPIC rejects. Keep route ends at GCs horizontal or vertical.

21Troubleshooting

I can't find the toolbar buttons.
They may be under the toolbar's » overflow arrow. Use Ctrl+Shift+R / Ctrl+Shift+M or Tools → Route (Waveguide / Metal) instead. If the menu is missing, check that salt\klroute\grain.xml exists and restart KLayout.
"Select a valid layer"
The layer chosen for a Custom waveguide or for metal does not exist. Pick one in the window's Layer list; layers that are in the technology but not yet in the layout are created for you.
"No route fits between … (bend radius …)"
The two points are too close for the bend radius, for example a U-turn whose legs are closer than twice the radius. Move the components apart or use a smaller radius.
"A port is too close to another device: there is no room to leave it"
Something sits right in front of the pin, or the pin points into its own device instead of out of it. The message names the end and its coordinates. Move the blocking device, or fix the pin direction.
The route was placed as a klroute Route cell instead of the PDK Waveguide.
Its first or last segment is diagonal. The PDK Waveguide cell needs horizontal or vertical ends; redraw the end segments in Manhattan mode.
Wires reopened as fixed cells on another PC.
klroute is not installed on that PC. Install it and reopen the file; the wire cells become editable again.
I moved a device and its routes stayed behind.
KLayout's Move tool does not re-route. Use Attach to move a device onto another's pin with its routes following, or redraw the route.
A label stayed behind when I moved its pad.
It was made before version 0.27, or the metal was drawn directly in the layout. Relabel it in Label mode with Replace ticked.
SiEPIC reports "Disconnected pin".
A route end or device port is not connected to anything. That is expected for unused ports.
Shortcuts changed to Ctrl+Alt+R / Ctrl+Alt+M.
Two klroute packages are installed; the one that loads second uses Ctrl+Alt. Remove one of them to get Ctrl+Shift back.

22Using it from a script

The routing core works in a KLayout macro, or standalone after pip install klayout:

from klroute import RouteSpec, draw_route, route

spec = RouteSpec(kind="waveguide", width=0.5, radius=10, bend="euler", cladding=2)
rt = draw_route(cell, layout.layer(1, 0), (0, 0), (250, 80), spec,
                start_dir="E", end_dir="W", cladding_layer=layout.layer(111, 0))
print(rt.length, rt.bends)

m1 = RouteSpec(kind="metal", width=3)
draw_route(cell, layout.layer(41, 0), (0, 0), (-40, 120), m1)   # auto directions

rt = route((0, 0), (100, 50), spec)   # geometry only: rt.centerline, rt.waypoints, rt.polygon()

If no route fits, route() raises RouteError.
